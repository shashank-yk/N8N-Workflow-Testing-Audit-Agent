# Future Improvements

Planned improvements for future versions:

- Add first-class support for more n8n trigger nodes, such as schedule, manual, form, chat, and email triggers.
- Add a safe demo `workflow.json` that users can import into n8n.
- Add GitHub Actions to run tests automatically on every push.
- Add richer scenario generation based on workflow node structure.
- Add per-workflow configuration for custom payloads and expected outcomes.
- Improve browser-based execution for manual workflows.
- Add screenshot summaries to reports.
- Add severity levels for failed scenarios.
- Add export options for Markdown, JSON, and PDF reports.
- Replace the deprecated `google.generativeai` package with the newer `google.genai` SDK.
- Add more tests around n8n API responses, Telegram command handling, and database persistence.
